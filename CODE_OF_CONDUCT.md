# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(CC BY 4.0).

**In short:** be respectful and constructive. Harassment, personal attacks, discriminatory language and
sustained disruption are not acceptable, in issues, pull requests, discussions or anywhere else the
project's name is on the room.

Technical disagreement is welcome and expected — argue about the code, not the person writing it. When
a decision is made, it gets recorded in `docs/adr/` so the reasoning outlives the argument.

## Scope

Applies to all project spaces, and to anyone representing the project publicly.

## Reporting

Report concerns privately to the maintainers via
[GitHub private vulnerability reporting](https://github.com/MassingCloud/MassingViewer/security/advisories/new)
(it works for conduct reports too, and is the only private channel this repo has) or by contacting
[@ibuilder](https://github.com/ibuilder) directly.

Reports are handled confidentially. Maintainers who cannot act impartially on a report will recuse
themselves from it.

## Enforcement

Maintainers follow the Contributor Covenant's four-step enforcement ladder — correction, warning,
temporary ban, permanent ban — choosing the step that fits the severity and the pattern. The full text
is linked above.
