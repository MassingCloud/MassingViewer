`galleryFor` gains `demote`, so a ribbon row leads with what the host can act on.

Breadth-first promotion filled the row from the alphabetically-first category. In the demo library that is
`Circulation`, so the ribbon led with a balustrade that is both a placeholder and unplaceable offline, while walls and
slabs sat in the flyout. Correct by the rule as written, and a worse tool — found by looking at the rendered panel
rather than at the code.

`demote` is a predicate, not a filter: demoted entries still appear if there is nothing better, so a discipline where
nothing is placeable shows its tiles rather than an empty row. And a predicate rather than kernel awareness inside
this package, because which operations exist is a kernel fact — the host joins the two.
